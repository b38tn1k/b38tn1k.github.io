### UI/Technical Details
- **Dark theme** with CSS custom properties (`#1a1a2e` base)
- **Left sidebar** for color palette; **top toolbar** for tools/actions
- **Checkerboard transparency** background via CSS pseudo-elements
- **Grid toggle** (G key or button) with CSS gradient overlay
- **Zoom controls** (1x–80x) with `+`/`−` buttons and Ctrl+= / Ctrl+−
- **Status bar** showing canvas size, cursor position, tool name, history depth
- **Keyboard shortcuts**: B (brush), E (eraser), G (grid), Ctrl+E (export)
- **Single `<canvas>`** scaled via CSS `transform: scale()` — no dual-canvas complexity
