### 🔴 Defect #1: Undo/Redo Logic Bug (Severity: **Medium**)

**Location:** Lines ~259–273 (`redo()` function)  
**Reproduction sequence:**
1. Draw on canvas → `saveState()` called at stroke end → undoStack=[state0, state1]
2. Click Undo → canvas reverts to blank, redoStack=[state1]  
3. Draw something new → `saveState()` pushes blank state AND **clears redoStack**
4. Click Undo again → only empty redo available (the original drawing is lost)
5. Click Redo → restores the empty/blank state, not the drawing

**Root cause:** `redo()` calls `saveState()` which **clears the entire redoStack** before restoring the state. This destroys any subsequent undone states that were redone after a new draw action.

**Impact:** After undo → redraw → undo → redo, the user cannot recover their second drawing. The history chain breaks at that point.

**Evidence in code:**
```javascript
function redo() {
    if (redoStack.length === 0) return;
    const nextData = redoStack.pop();
    saveState(); // ← saveState clears redoStack: redoStack = [];
    ctx.putImageData(nextData, 0, 0);
    render();
    updateUndoRedoUI();
}
```

**Fix suggestion:** Store `nextData` first, then clear redo manually without calling the full `saveState()`:
```javascript
function redo() {
    if (redoStack.length === 0) return;
    const nextData = redoStack.pop();
    // Save current state to undo stack manually (without clearing redo)
    undoStack.push(ctx.getImageData(0, 0, state.width, state.height));
    if (undoStack.length > MAX_UNDO) undoStack.shift();
    ctx.putImageData(nextData, 0, 0);
    render();
    updateUndoRedoUI();
}
```

### ⚠️ Defect #2: Eraser Boundary Issue with Brush Size > 1 (Severity: **Low**)

**Location:** `drawAt()` function — eraser path uses `ctx.clearRect(x - half, y - half, size, size)`  
**Issue:** `clearRect` expects x,y as top-left corner. When brushSize is 3, `half = 1`, so it clears from `(x-1, y-1)` with size 3 — but if the cursor is near the canvas edge (e.g., x=0), this would attempt to clear at `-1` which is silently clipped by the browser but could show artifacts depending on rendering context.

**Impact:** Minimal — browser handles out-of-bounds rects gracefully. Only noticeable at exact canvas edges with larger brush sizes.
